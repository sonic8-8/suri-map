## PostGIS 적재 방법

```python
import geopandas as gpd
from sqlalchemy import create_engine

# 예시: 광산구 도로경계면 적재
gdf = gpd.read_file('광산구/N3A_A0010000.shp', encoding='cp949')
gdf = gdf.set_crs('EPSG:5179').to_crs('EPSG:4326')
gdf = gdf.drop(columns=['Shape_Leng', 'Shape_Area'], errors='ignore')

engine = create_engine('postgresql://user:pw@localhost:5432/dbname')
gdf.to_postgis('road_boundary', engine, if_exists='append', index=False)
```

- 5개 구의 동일 레이어를 하나의 테이블에 `if_exists="append"`로 순차 적재
- `Shape_Leng`, `Shape_Area`는 PostGIS에서 `ST_Perimeter()`, `ST_Area()`로 계산 가능하므로 제거 권장
- GIST 인덱스는 `gdf.to_postgis()` 호출 후 별도 생성 권장:
  ```sql
  CREATE INDEX ON road_boundary USING GIST (geometry);
  ```
