# 수색 차수로 이력을 묶어 인수인계

구역에 차수 숫자만 붙이면 과거 경로·구역·마커와 현재 수색을 함께 구분하기 어렵다. 수색 차수인 OperationalPeriod로 기록을 묶고, 업무폰의 근무 교대인 DutyShift와는 분리하기로 했다. 차수를 바꿔도 과거 기록을 옮기거나 덮어쓰지 않고, 메모와 사실 중심 요약으로 다음 근무자가 맥락을 이어받도록 한다.

현재 확인: [차수 전환·메모·요약](../handover.md)에 구현과 남은 요구를 모았다. 차수 전환 구현과 늦은 기록의 요약 재생성·실패 복구는 별개이며, 원문의 UI 재시도 설명도 이후 읽기 전용 요구와 다르다. 원천 기록과 차수 구분을 보존한다는 선택을 요약 기능 전체의 완성으로 간주하지 않는다.

기록: 2026-04-27 · ADR-0021 대체 · [ADR-0029 원문](https://github.com/sonic8-8/suri-map/blob/7f2ea69ad46fa47ce07a6db6c66861fd95731978/docs/adr.md#adr-0029-op-기반-인수인계와-수색-이력-요약). ADR-0021의 근거 조사 사본 부재는 [원문 안내](README.md#원문과-이후-기록)에 남겼다.
