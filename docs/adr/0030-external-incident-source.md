# 외부 사건·배정을 가져와 수색 지원

Suri-Map의 역할은 수색 지원이므로 사건 생성·지원 부대 배정 업무까지 내부에서 다시 만들지 않기로 했다. MVP에서는 실제 경찰 시스템 대신 mock 112·seed의 사건·실종자·배정 결과를 가져온다. 외부 원천과 수색 기록의 역할을 나누지만, 실제 원천 연동·인증·변경 반영은 별도로 확인해야 한다.

현재 확인: [사건 가져오기·배정](../features/incident-lifecycle.md)에는 수동 요청 외에 웹훅 가져오기, 배정 추가 전용 처리, 원천 ID와 내부 ID의 구분을 기록했다. 어댑터가 있다는 사실만으로 실제 112 연결이나 모든 배정 변경을 지원한다고 판단하지 않는다.
