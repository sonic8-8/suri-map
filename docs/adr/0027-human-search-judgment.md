# 수색하지 않은 구역을 자동으로 단정하지 않음

ADR-0018은 전체 구역에서 완료 구역과 경로 주변을 빼 미확인 구역을 표시하려 했지만, 경로 주변 폭과 지형에 따라 잘못된 판단을 유도할 수 있었다. 이 기능을 제외하고 사람이 차수별 경로·완료 구역·메모를 보고 판단하도록 정했다. 자동 추천의 편의보다 기록의 근거와 인수인계에 집중하며, PostGIS는 공간 저장·조회 용도로 유지한다.

현재 확인: 자동 판단을 제외하는 범위는 [제품 요구](../prd.md)에 남아 있다. 이동 경로를 완료 구역과 같은 의미로 해석하지 않으며, 실제 경로·구역 표시는 [상황판](../situation-board.md)에서 확인한다. 이번 문서 정리로 모든 화면·응답의 자동 판단 문구 부재를 시험한 것은 아니다.
