# 기록 시각과 서버 수신 시각 구분

오프라인에서 30분 전에 남긴 단서가 재전송됐을 때 지금 발견한 단서처럼 보이면 판단을 그르칠 수 있다. 이를 피하려고 단말 기록 시각은 현장 발생 시점을, 서버 수신 시각은 도착 시점을 나타내도록 나누고 시계 보정 정보를 함께 남기기로 했다. 단말 시각은 오차가 있으므로 기록 시각·수신 순서·시계 오차를 같은 값으로 취급하지 않는다.

현재 확인: [오프라인 시각 처리](../offline-sync.md)와 [GPS 측정 시각·수집 순서](../search-path.md)를 별도로 확인한다. 원문은 모든 이벤트의 `client_ts`·`server_ts`·`clock_offset_ms`와 서버 시각 기반 충돌 판정을 요구했지만, 전체 적용을 확인한 상태는 아니다. 기록 시각과 수신 시각의 차이만으로 통신 지연과 단말 시계 오차를 구별할 수 있다고 가정하지 않는다.
