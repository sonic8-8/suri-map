# 사건 종료를 되돌리지 않고 개인정보 정리

실종자 정보의 원천은 112에 두고, Suri-Map에는 수색 운영에 필요한 자료만 유지하려 했다. 종료 후 사용자 재오픈을 허용하는 대신 종료를 되돌릴 수 없는 상태로 정하고 실종자 정보·사진 자료를 정리하기로 했다. 이 선택은 종료 확인과 데이터별 보존·파기 범위를 분명히 해야 하며, 오프라인 단말의 미전송 기록과도 충돌 없이 처리해야 한다.

현재 확인: [사건 종료](../features/incident-lifecycle.md#사건-종료와-개인정보-제거)는 상태 변경과 실종자 행·사진 주소 제거를 수행하지만, 이것만으로 사진 파일·단말 자료까지 삭제됐다고 판단하지 않는다. 실제 연결 차이와 미정 보존 기준은 [데이터 파기](../features/data-retention.md), 미전송 원본 처리는 [오프라인 종료 처리](../features/offline-sync.md#사건-종료-후-남은-기록)에 남겼다. 원문에 언급한 관리자 복구 절차도 구현 완료로 옮기지 않는다.
