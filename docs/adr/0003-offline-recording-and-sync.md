# 통신이 끊겨도 기록하고 나중에 전송

현장 통신이 끊겼다는 이유로 수색 기록까지 잃지 않도록, 서버 응답을 기다리는 대신 Android Room에 기록과 미전송 작업을 저장하기로 했다. Outbox에 남긴 요청은 WorkManager로 재시도하고 서버는 멱등키로 중복 반영을 막는다. 즉시 서버 반영을 전제하지 않는 대신 전송 순서·충돌·최종 실패·사건 종료 후 처리가 필요하다.

현재 확인: [로컬 저장·재전송](../features/offline-sync.md)에서 호출 흐름과 남은 차이를 확인한다. 원문의 ‘30분 이상 유실 0건’은 이번 검증 결과가 아니며, 서버 시각 기준의 일괄 덮어쓰기 정책도 현재 모든 쓰기의 동작으로 간주하지 않는다. GPS는 묶음을 만들기 전 메모리에 머무르는 구간이 있어 [실제 저장 흐름](../architecture.md#경로-기록부터-상황판-표시까지)과 구분한다.
