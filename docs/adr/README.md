# 설계 결정과 변경 이력

구조를 선택한 이유나 과거 ADR 번호를 찾을 때 읽는다. 2026-09-21에 기존 ADR 36개를 검토해, 계속 참고할 선택 이유는 개별 파일로 남기고 나머지는 아래 이력으로 줄였다. 현재 구성은 [Architecture](../architecture.md), 필요한 동작과 구현 차이는 각 기능 문서에서 확인한다.

원문의 `Accepted`와 `Current note`는 작성 당시의 판단이다. 개별 파일의 확인 내용도 코드·설정을 대조한 결과이며, 제품 테스트·배포·현장 검증의 통과 기록은 아니다. 이번 정리는 새 기술이나 정책을 채택한 작업이 아니다.

## 요약으로 남긴 이력

이미 대체된 결정, 당시 도구·일정, 기능 문서에 남긴 요구는 별도 ADR 파일로 복제하지 않았다. 아래의 ‘재검토’는 기존 요구와 현재 구현이 다르다는 뜻이며, 이번에 어느 쪽으로 확정했다는 뜻이 아니다.

| 번호·작성일 | 당시 선택과 이유 | 대체 관계·현재 확인 위치 |

| ADR-0001 · 2026-04-21 | 5주 MVP를 제공받은 단일 EC2·Compose로 운영해 배포 복잡도를 줄인다. 단일 장애점·자원 경합은 감수한다. | 현재 서버 사양·백업 보장으로 사용하지 않는다. [배포·관측 설정](../architecture.md#배포와-관측)에서 확인한다. |
