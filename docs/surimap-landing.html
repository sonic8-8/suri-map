현장 경로와 구역 판단을 한 화면에서 공유합니다.

Suri-Map은 폴리폰의 GPS 경로, 현장 마커, 오프라인 기록, OP별 인수인계 메모를 웹 상황판으로 모아 중복 수색과 누락된 전달을 줄이는 운영 보조 시스템입니다.

무전으로 흩어지는 수색 기록을 구조화된 운영 화면으로 바꿉니다.

Suri-Map은 112 공식 기록 시스템을 대체하지 않습니다. 현장에서 이미 일어나는 수색과 보고를 더 잘 공유하도록 돕는 보조 도구입니다.

01

PolicePhone 기준 경로 기록

개인 추적이 아니라 팀 업무폰·순찰차 업무폰 기준으로 수색 경로를 기록하고 OP와 근무 구간에 연결합니다.

02

웹 전용 지휘 상황판

구역 분할, OP 생성, 구역 완료, 차량·도보 보정은 데스크톱 웹 상황판에서 처리합니다.

03

앱 전용 현장 입력

단서, 발견, 지형, 지원 요청, 운영 NOTE 마커는 폴리폰에서 GPS 기반으로 빠르게 남깁니다.

04

OP 기반 인수인계

경로, 마커, 완료 구역, 메모, 수색 이력 요약을 OP 단위로 묶어 다음 교대가 원본을 확인합니다.

현장 입력과 지휘 조작을 분리해 책임 경계를 선명하게 유지합니다.

모바일은 현장 기록에 집중하고, 웹은 공용 상황판과 지휘 조작에 집중합니다. 채널 경계는 서버에서도 검증됩니다.

Android 폴리폰 현장 입력
1
사건 오프라인 패키지 적재

사건 메타, 실종자 정보, 구역, 초기 마커, 지도 타일을 한 번에 다운로드합니다.

2
수색 시작과 GPS 기록

현재 OP와 DutyShift에 연결된 PolicePhone 경로를 지속 기록합니다.

3
현장 마커 생성

유형 선택 중심의 바텀시트로 단서·지원 요청·운영 NOTE를 빠르게 남깁니다.

Web 상황판 지휘 판단 보조
1
구역 분할과 담당 배정

OVERALL, UNIT, TEAM 계층으로 수색 범위와 담당 구역을 관리합니다.

2
OP 비교와 경로 보정

이전 OP와 현재 OP의 경로·마커·완료 구역을 겹쳐 보고 차량·도보 구간을 보정합니다.

3
종료와 개인정보 파기

사건 종료는 terminal 흐름이며, 실종자 개인정보는 active 데이터에서 제거됩니다.

자동 판단 금지

시스템은 누락 구역 확정, 다음 구역 추천, 위험도 판단을 수행하지 않고 원본 기록을 정리합니다.

공식 기록 대체 금지

112 계열 시스템의 원본 기록을 대신하지 않고, 현장 공유와 운영 판단 보조 역할에 집중합니다.

오프라인 기본값

약전파와 단절 상태에서도 경로와 마커를 로컬에 저장하고 복구 시 중복 없이 동기화합니다.

통신이 끊겨도 기록은 멈추지 않습니다.

현장 단말은 Room/SQLite와 Outbox 패턴으로 GPS·마커·사진 메타데이터를 보존합니다. 복구 후에는 idempotency와 재전송 큐로 중복 생성 없이 상황판에 반영합니다.
