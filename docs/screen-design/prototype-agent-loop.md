# 프로토타입 제작 참고 기록

팀 프로젝트에서 화면 시안을 만들 때 사용한 접근과 검수 환경 주의사항을 보존한다. 매 요청에 긴 프롬프트를 주입하거나 정해진 횟수만큼 재생성하는 절차는 현재 작업 지침으로 사용하지 않는다. 현재 작업은 [AGENTS.md](../../AGENTS.md)를 따른다.

## 당시 검토 방식

- 화면 정의와 컨텍스트 골격을 입력으로 시안을 만들고, 지도·패널·핵심 행동을 검토해 발견한 문제를 다음 시안에 반영하는 절차를 정했다.
- KRDS 시민포털의 넓은 여백과 일반 지도 앱의 검색·장소 중심 화면을 그대로 옮기면 수색 상황판에 필요한 정보가 밀려나는 점을 검토했다.
- Web 지휘 화면과 Android 현장 입력 화면의 목적을 나눠 시안을 만들었다.
- 시안의 상태 표현과 실제 API·DB·알림 연동 검증은 별개로 다뤘다.

세부 검토 항목은 [anti-patterns.md](./anti-patterns.md), 당시 토큰 가정은 [dense-tokens.md](./dense-tokens.md)에 있다. 새 작업에서는 필요한 항목을 현재 요구·화면과 대조한다.

## 검수 환경에서 확인했던 문제

한국어 폰트가 없는 환경에서는 HTML 시안의 한글이 네모 글리프로 표시됐다. CSS의 폰트 이름뿐 아니라 캡처 환경에 해당 폰트가 설치되어 있는지도 확인해야 했다. 당시에는 Pretendard 또는 Noto Sans 계열을 검수 환경에 준비했다.

시안 본문과 검수 메타·변형 비교를 한 화면에 섞으면 실제 화면 크기와 정보 배치를 판단하기 어려워, 리뷰를 별도 파일로 보관했다.

## 남아 있는 자료

[화면 자료 목록](./README.md)에서 시안·프로토타입·실기기 기록을 찾는다. 기존 파일의 `lo-`·`hi-`·`proto-` 접두어와 버전 번호는 당시 산출물 구분이다. 과거 리뷰에 적힌 이 문서의 절 번호는 작성 당시 Git 버전을 가리킨다.
