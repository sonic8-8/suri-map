# 화면 설계의 현장 가정과 조사 출처

현장 입력 앱과 지휘 상황판을 구분한 이유를 남긴다. 아래 환경·수치는 관찰로 모두 검증한 사실이 아니라 당시 제품 요구·사용자 진술·설계 추정이 섞인 가정이다. 출처와 한계도 이 문서에서 함께 확인한다.

## 사용자 조사 출처와 한계

| 기록된 자료 | 확인 범위 |
|---|---|
| 2026-04-24 경찰 대면 인터뷰 | 옛 PRD가 `2026-04-24_police_in_person_interview.md`를 인용했다. 저장소에 원본이 없으며 외부 보관 위치·대상 소속·동의 여부는 미확인 |
| 2026-04-15 요구사항 정의 | 옛 PRD가 `2026-04-15_requirements_definition.md`를 인용했다. 저장소에서 원본을 찾지 못했으며 외부 보관 여부는 미확인 |

원문 부재를 인터뷰를 하지 않았다는 뜻으로 해석하지 않는다. 재인용만 보고 직접 확인한 조사라고 보고하지도 않는다. 인원·업무폰 대수는 사용자 진술, 앱·웹 역할은 제품 요구, 정보 밀도·터치 크기는 설계 추정, 근거 없이 시안을 위해 정한 수치는 시연 가정으로 구분한다.

## 현장 입력 앱과 지휘 상황판

| 대상 | 고려했던 환경 | 화면에서 확인할 점 |
|---|---|---|
| Android 업무폰 | 야외·야간·우천·장갑, 도보·차량 이동, 무전과 한 손 조작 | 큰 터치 영역, 하단 핵심 행동, 짧은 읽기, 삭제·종료 확인 |
| Android 업무폰 | 장시간 오프라인과 짧은 재접속 반복 | 로컬 기록과 서버 전송 완료 구분, 미전송 원본 보존, 자동 복구 상태와 처리 불가 사유 |
| Android 업무폰 | 교대 사용·장시간 기록·저전력 | 운용 계정·근무 구간 구분, 기록 지속 여부, 배터리·GPS·패키지 상태 |
| Web 지휘 PC | 무전·전화 병행, 장시간 확인, 여러 사건 전환 | 사건·수색 차수 맥락 유지, 마지막 갱신 시각, 지도와 상세를 함께 확인 |
| Web 지휘 PC | 여러 사람이 모니터를 같이 봄 | 먼 거리의 식별 가능성, 색 외 라벨·형태, 확대·키보드 접근 |

웹 상황판은 데스크톱, 앱은 현장 입력이라는 제품 경계를 유지한다. 업무폰 수와 인원 수를 같게 세지 않는다. 팀·순찰차 공유 운용은 당시 가정이며 개인·공유 계정과 등록 단말의 실제 관계는 [인증](../features/authentication.md)을 대조한다. 수색 차수(OP)와 근무 교대(DutyShift)는 다른 개념이다.

## 시연용 규모와 수치의 한계

| 당시 가정 | 용도·주의 |
|---|---|
| 광주 실종팀 1명·업무폰 1~2대, 지구대 1팀 약 6명, 기동대 2부대 약 12대 | 사용자 진술·추정을 섞은 산정. 합계 약 15~20대도 실측 최대 수용량이 아님 |
| 업무폰 12~15대 식별, 20대 초과 묶음 표시, 마커 40개 | 시안의 정보 밀도 가정. 서버 부하테스트의 468대 조건과 별개 |
| 수색 차수 약 5개 비교, 목록 10~12행, 사건 3건, 근무 구간 24시간 | 화면 배치 가정. 수색 차수 누적·선택 개수의 업무 상한이 아님 |
| Web 1920×1080, 앱 412×892, 좌측 280px·우측 360px | 시안 캔버스와 패널 폭. 실제 단말의 px·dp·글꼴 배율과 대조 필요 |
| 지도 전체 표시 / 시트 확장 후 지도 50% 이상, 상시 배지 3개+강조 알림 1개 | 화면 배치 목표. 모든 기기·알림 조합에서 확인한 결과가 아님 |
| 미전송 5건 강조·20건 경고, GPS 5초·전송 10초 | 오래된 시연 가정. 현재 수집·전송 주기나 복구 목표를 확정하는 근거가 아님 |
| 오프라인 30분 이상·근무 8시간 이상·배터리 20%, 조도 0~50,000lux 이상 | 시험 환경 후보. 현장 분포·허용 지연·배터리 정책의 검증값이 아님 |

시연 범위를 고정한다는 이유로 새 관찰·사용자 피드백을 미루지 않는다. [현재 GPS·전송 검토](../features/search-path.md)와 [화면 확인 항목](screen-guidelines.md#화면을-바꾼-뒤-확인할-것)을 따로 확인한다.

## 남겨 둘 확인 상황

- 산악 야간, 우천·장갑·한 손 조작, 차량 동승자의 입력
- 1시간 오프라인 → 10초 재접속 → 다시 단절되는 동안 기록·전송 상태 구분
- 지원 부대 합류, 새 근무 시작, 수색 차수 비교, 요약 실패, 사건 종료와 파기
- 실제 업무폰 수·공유 방식·동시 사건 수·교대 패턴, 다른 지역 규모로 일반화 가능한지
- 주야간·색 구분·확대·오래된 PC 환경에서 읽기와 조작이 가능한지
- 인수인계 확인 순서·차수 변경 사유, 마커 생성 빈도·유형, 112·실종프로파일링과의 화면 전환·운영 기록

새 자료에는 일자·수집 방식·대상 범위·동의/익명화, 직접 관찰과 해석, 영향을 받는 요구·후속 질문을 짧게 남긴다. 소수 인터뷰를 전체 경찰 업무로 일반화하지 않는다. 원본 확보와 추가 조사 가능성도 아직 확인할 대상이다.
