# Gov Portal — UI Kit

A hi-fi recreation of a typical citizen-facing Korean government portal homepage. Combines the official banner, header (PC), hero search, quick services, news/policy section, and the standard footer from the Whole-of-Government UI/UX Common Guide.

## Files
- `index.html` — full assembled homepage with three click-thru screens (home → service detail → applied)
- `Header.jsx` — top strip + utility + main nav
- `Footer.jsx` — related sites + MI + legal block
- `HeroSearch.jsx` — main search section
- `QuickServices.jsx` — 자주찾는 서비스 grid
- `NewsSection.jsx` — 정책뉴스 cards
- `EmergencyNotice.jsx` — 긴급공지 stripe
- `ApplyDetail.jsx` — service detail screen
- `ApplyDone.jsx` — applied confirmation screen

Open `index.html` to interact. Click a quick service or "신청하기" to traverse the flow.
