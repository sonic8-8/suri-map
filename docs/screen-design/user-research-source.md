# 사용자 리서치 소스

상태: 초안. 시연 baseline은 freeze됨. 이 문서는 v2 이후 참고 자료 누적용.

## 정책 (중요)

- **MVP 시연 baseline은 freeze**. 이 문서의 인터뷰/관찰 결과로 토큰·매트릭스·검수 게이트를 변경하지 않는다.
- field-context.md/dense-tokens.md의 △ 표기는 "**광주 광역 시연 범위 외 가정**"으로 재정의. 시연 범위 외이므로 변경 트리거가 아니다.
- 새 인터뷰 결과는 **MVP 출시(2026-05-22) 이후 v2 검토용 참고 자료**로만 누적한다.
- 5주 MVP 일정 동안 개발 계획에 영향을 주는 인터뷰 변경은 받지 않는다.

## 목적

- field-context.md와 anti-patterns.md의 가정 출처를 추적 가능하게 한다.
- 시연 baseline의 광주 광역 가정이 어디서 왔는지 명시한다.
- v2 이후 검토용 참고 자료를 누적한다.

## 2. 시연 baseline 가정의 출처

field-context.md §2.0.1, dense-tokens.md §1.1의 1차 산정값은 **광주 광역시 시연 가정**에 기반한다. 출처 분류:

- **사용자 진술**: 광주 광역시 운영 관련 사용자가 직접 진술한 값. (예: 실종팀 1명, 기동대 2부대 약 12대)
- **PRD 사실**: PRD/spec 문서에서 도출한 값. (예: 1팀 = 폴리폰 1대 — FR-33)
- **dashboard/UI 추론**: 일반 운영 dashboard·rugged UI 베스트 프랙티스에서 가져온 값.
- **시연 가정**: 위 셋 어디에도 없으나 시연 진행을 위해 박은 값. △ 표기.

출처가 다르더라도 **시연 baseline은 freeze**다. v2 이후 변경은 별도 검토.

## 3. v2 이후 참고용 누적 항목

아래는 MVP 출시 후 v2 검토용 참고 항목. **MVP 시연 baseline은 freeze이므로 이 항목들로 토큰·매트릭스·게이트를 변경하지 않는다.**

### 3.1 v2 참고용

- 폴리폰 야외 사용 환경 관찰 (조도·장갑·무전 동시 사용)
- 상황판 다중 사건 운영 시 사건 전환 빈도·맥락
- DutyShift 인수인계 시점에 실제로 보는 정보·순서
- OP 전환 시점(재수색·범위 변경)에 보는 정보·순서
- 마커 생성 빈도·유형별 비율
- 미전송 큐가 N건 누적되는 실제 상황 (오프라인 지속 시간 분포)
- 1팀당 폴리폰 1대 운용 실태 — 6명이 1대를 어떻게 공유하는지
- 광역 사건에서 동시 운용 폴리폰 수 (지구대/파출소 + 실종팀 + 지원 부대 합산)
- 광주 광역 사건의 동시 운용 폴리폰 수 정확값
- 광주 지구대 1팀 인원 (6명 추정 검증)
- OP 동시 overlay 시각 권장 한계 (5차에서 가독성을 잃는지)
- 광주 실종팀 1명이 동시에 모니터링하는 사건 수
- 광주 교대 패턴 (8시간 3교대 vs 12시간 2교대 vs 기타)
- 다른 지역·다른 규모 일반화 가능성 (서울·도서지역 등)
- 지구대/파출소 초동 대응 시 폴리폰 사용 패턴
- 순찰차 폴리폰 운용 (운전·조수석)
- 색맹 사용자 비율 (의무·경찰 통계)
- 야간 운용 빈도
- 다른 경찰 IT 시스템과의 화면 전환 (112, 실종프로파일링)
- 운영 로그 사용자 화면 요구 여부 (현재 PRD §8.7 외)
