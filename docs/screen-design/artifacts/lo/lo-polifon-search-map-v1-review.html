핵심 디자인 결정

  • 다크 base: 야외 직사광선 + 야간 운용 + 배터리 절약 (field-context §1.1). 라이트 모드 전환은 v2.
  • thumb zone: 화면 하단 1/3에 모든 primary CTA. "마커 생성"은 가장 큰 72px 높이로 강조 (가장 자주, 가장 빠르게).
  • 자기 폴리폰 강조 (FR-25): 시안색 outline + 더 큰 점 + 경로 굵기. 다른 폴리폰과 명확히 구분.
  • 담당 TEAM 강조: 자기 배정 구역만 시안 outline. 다른 TEAM은 점선 dimmed. "내가 어디 책임지는지" 즉시 판단.
  • App Bar 정보 우선순위: 사건명 → OP/DutyShift → 동기화 상태. 무전 청취 중에도 글랜스로 인지.
  • "내 위치" 큰 버튼 (우하단 56px): 지도 panning 후 즉시 자기 위치 복귀. 가장 빈번한 동작.
  • 강조 알림 banner: PERSON_FOUND·SUPPORT_REQUEST 수신 시 지도 상단 banner (variant 참조). 명시적 dismiss까지 유지 (anti-patterns §6.1).
  • 마커 시각: web v1.3과 동일 7종 SVG 글리프. 공통 아이콘 시스템.
  • 웹 상황판 진입 없음: anti-patterns §1.6.4. 헤더 어디에도 상황판 메뉴 없음. 사건 목록만 진입 가능.

anti-patterns 검수

  • PASS §1.6.1 OP 라벨에 "OP 3차 · 재수색" + DutyShift는 별도 chip ("DutyShift · 14:00 인계 (3교대)")
  • PASS §1.6.2 폴리폰=인원 표현 X. 담당 TEAM은 "기동대 1부대 A팀"
  • PASS §1.6.3 마커 생성 CTA가 가장 큰 강조 (모든 계정 동등)
  • PASS §1.6.4 웹 상황판 진입 메뉴 없음
  • PASS §1.6.5 동시 active OP 1개 ("OP 3차" 단독 표시)
  • PASS §1.6.7 사건 재오픈 UI 없음
  • PASS §1.6.10/§1.6.11 마커 = 아이콘 + 라벨 칩 (web v1.3과 동일)
  • PASS §2.2 검색바 중앙 없음
  • PASS §2.5 "내 위치" 버튼이 화면 중심 액션 아님 (마커 생성이 최대 강조). 단 폴리폰 화면이라 "내 위치"는 보조 강조 OK
  • PASS §3.1 마커 = 아이콘 모양 + 라벨 + (high-fi에서 색)

  • 메모 §4.5 오프라인 표출은 default state에서 동기화 pill만. 오프라인 상태 variant에서 별도 강조 필요
  • PASS §4.6 미전송 큐 chip "미전송 1건" — dense-tokens §1.2 임계 5건/20건 미만이라 일반 톤

v1 검토 필요 / 미정

  • 마커 생성 화면으로 이동: "마커 생성" CTA → 마커 생성 바텀시트 화면 (별도 low-fi). 어떻게 push되는지 (모달 vs 화면 전환) 명시 필요
  • 지도 panning 시 "내 위치" 버튼 동작: 자기 위치로 즉시 복귀 + 자동 추적 모드 토글 가능?
  • App Bar의 "사건 목록" 버튼: 사건 진입 중 사건 목록 복귀 시 수색 기록 어떻게? 백그라운드 유지?
  • 레이어 컨트롤 버튼: 우상단 "레이어"는 마커 유형/구역/경로 토글 액세스. 별도 시트로 펼침 가정 — 시안 미설계
  • OVERALL outline 표시 범위: 화면이 좁아서 OVERALL이 화면 밖일 가능성. zoom out 시 자동 fit 필요
  • 다른 폴리폰 라벨: web과 달리 폴리폰 화면은 다른 폴리폰 점 라벨이 거의 없음 (가독성). tap 시 라벨 노출 정책 결정
  • 바텀 시트 펼치기 (드래그): 현재는 펼침 상태만 표시. 접기 시 "수색 카드"만 + 큰 마커 생성 CTA 유지 정책
  • 강조 알림 banner와 status bar 충돌: 둘 다 지도 위 영역. banner 표시 시 status bar 가리지 않아야 함
  • "수색 시작" CTA의 GPS 권한 요청 흐름: 첫 시작 시 OS 권한 요청 모달. variant 미설계
  • 장갑 모드: dense-tokens §5 touch-glove 56px 적용. 정상 모드 vs 장갑 모드 자동 감지 또는 토글 v2
