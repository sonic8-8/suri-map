핵심 디자인 결정

  • 유형 선택만으로 저장 가능 (FR-15): 메모/사진은 선택. 한 손 빠른 입력.
  • 5종 마커 한 화면 (FR-30, dense-tokens §1.2): 2×2 + full-width 1개. 스크롤 없음.
  • 지원 요청 sub-type 별도 (FR-17): 단일 마커 보지 않고 sub-type 직접 선택. 지도에서 즉시 식별.
  • 자동 입력 시각화: 위치/시각/작성자가 자동임을 명시. 사용자가 입력 안 해도 됨을 인지.
  • thumb zone 100%: 저장 버튼 시트 가장 아래 + 56px. 모든 type-btn 84px (장갑 56px 이상).
  • 다크 base: 수색 중 지도와 일관. 야외 가시성.
  • 아이콘 = web v1.3과 동일 7종: 공통 시각 시스템.
  • 배경 지도 dimmed + 핀 강조: 어디 마커 찍히는지 시트 위에서도 확인 가능.

v1 검토 필요

  • 지원 요청 expand 인터랙션: 현재 mock은 항상 표시. 실제는 "지원 요청" type-btn 탭 → sub-type 영역 expand 애니메이션 high-fi에서 결정.
  • 실종자 발견 강조: PERSON_FOUND는 destructive 아니지만 영향이 큼 (사건 종료 가능성). confirm 다이얼로그 추가 검토.
  • 위치 수동 조정 (FR-14): 자동 위치가 부정확한 경우 사용자가 지도에서 핀 드래그. 이 시트에서 [위치 조정] 버튼 추가? 또는 시트 닫고 지도에서?
  • 메모 음성 입력: 야외·장갑 환경에서 키보드 입력 어려움. 음성 입력 토글 v2.
  • 저장 후 흐름: 시트 닫힘 → 지도 복귀 + toast "마커 저장됨". 토스트 위치/지속 결정 필요.
  • 사진 thumbnail 표시: 현재 mock은 카운트만. 실제는 첨부된 사진 썸네일 grid 표시 (지웠던 자리 + 추가 버튼).
  • type-btn 글자 길이: "실종자 발견"이 가장 김. high-fi에서 폰트 크기·줄바꿈 확인.
  • SUPPORT_REQUEST sub-type "기타 지원" 라벨: 너무 모호. 실제 운영에서 어떤 케이스인지 확인 필요.
