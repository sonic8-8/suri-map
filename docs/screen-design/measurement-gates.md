# 화면 검증 항목과 옛 목표값

화면을 바꿀 때 무엇을 직접 확인할지 고르는 참고 자료다. 모든 문서 칸을 채운 뒤에만 구현하도록 하는 승인 절차는 사용하지 않는다. 아래 수치는 당시 제안값이며 실측 합격 결과·새 운영 기준이 아니다.

## 관찰하려던 항목

옛 G 번호는 리뷰 원본을 찾기 위해 남겼다. 숫자가 필요한 시험은 목적·근거·환경·사용자가 확인할 결과를 먼저 정한다.

| 옛 항목 | 확인 방법·당시 목표 | 해석할 때 주의 |
|---|---|---|
| G1-1 업무폰 식별 | 1920×1080 지도에서 5초 관찰 후 회상. 약 12~15대, 20대 초과 묶음 표시 | 광주 시연 추정. 서버 수용량과 무관 |
| G1-2 마커 식별 | 40개 표시에서 유형·위치 확인 | 현장 검증값 아님 |
| G1-3 차수 비교 | 1·2·3·5·7·10차 겹침 확인, 약 5차까지 식별 제안 | 6차 이상 선택 금지가 아니라 가독성 검토 |
| G1-4 지도 점유율 | 시트 닫힘/확장 픽셀 면적 확인 | 원문에는 X% 미정 표기도 있었음. 현장 가정의 100%/50%와 구분 |
| G1-5 다중 사건 | 사건 3건의 전환·맥락 확인 | 운영 규모 추정 |
| G2-1 글자 대비 | Web 4.5:1·업무폰 7:1 목표 제안 | 실제 글자·배경·상태 조합의 측정 및 적용 접근성 기준 확인 필요 |
| G2-2 색 구분 | 세 색각 시뮬레이션, 색+형태+라벨 | 시뮬레이션 계획이며 통과 기록 없음 |
| G2-3 확대 | 브라우저 200%에서 핵심 정보·조작 접근 | 고정 캔버스 시안만으로 검증 불가 |
| G2-4 야외 | 50,000lux·1m 읽기 제안 | 실험 환경·현실성 미확인. 확정 합격선 아님 |
| G2-5 키보드 | Tab 순서·초점·핵심 행동 도달 | 실제 구현에서 확인 |
| G2-6 지도 글자 | 주간·야간·위성 위 라벨 대비 | 배경·외곽선 포함 |
| G3-1 마커 입력 | 완료까지 탭 수, 3탭 이내 제안 | 최소 기록과 사진·메모 완료의 범위부터 구분 |
| G3-2 최신성 식별 | 오래된 업무폰을 5초 이내 찾기 제안 | 운영 판단과 통신 상태 구분 |
| G3-3 차수 차이 | 10초 이내 차이 인식 제안 | 사용자·입력 규모가 정의되지 않음 |
| G3-4 사건 전환 | 5초 이내 맥락 파악 제안 | API 시간과 사용자 인지 시간은 별개 |
| G3-5 엄지 도달 | 모든 핵심 행동의 한 손 도달 | 화면 그림뿐 아니라 실제 단말에서 확인 |
| G4-1 장갑 | 입력 정확도 90% 이상 제안 | 장갑·우천·동작 수 미정. 현장 합격 기준 아님 |
| G4-2 오프라인 | 1초 이내 상태 인지 제안 | 연결 변화·미전송 상태를 실제 전환으로 시험 |
| G4-3 미전송 강조 | 누적 건수에 따른 표현 | 5/20건은 옛 가정. 정상 대기와 처리 불가를 구분 |
| G4-4 삭제·종료 | 명시적 확인과 취소 가능성 | 500ms 길게 누르기만으로 확정 금지. 1.5초 누르기 대안도 검증 전 후보였음 |
| G5-1·2 상태 | 정상·빈 값·실패·권한·오프라인·종료의 실제 흐름 | 문서 빈칸 0개·시안 존재를 제품 통과로 대체하지 않음 |
| G5-3 단순 보기 | 숨긴 항목과 원본 불변 확인 | 토글 존재만 검사하지 않음 |
| G6-1~4 잘못된 판단·지도 표현 | 자동 누락·추천·위험 판단, 요약의 지시·추측, 제품 밖 지도 기능 확인 | [혼동 사례](anti-patterns.md) 참고 |
| G6-5·7 도메인 의미 | OP/근무 교대, 폰/인원, 구역/경로, 생성/수정, 종료 구분 | 원문 세부 7개 항목은 Git 원문 보존 |
| G6-6 권한 | 채널·역할·사건 배정별 조회/명령 확인 | 화면 버튼뿐 아니라 서버 거부도 확인 |

## 확보한 증거의 한계

- [2026-05-11 실기기 QA](artifacts/device-qa/AUI-T14/report.md)는 일반 실행의 접속 실패와 디버그 화면 표시를 확인한 기록이다. 실제 API·네트워크 복구·Knox·현장 조작 검증이 아니다.
- UI XML의 터치 크기 검사는 px 기준이다. 실제 단말 밀도를 확인하지 않은 채 48dp 접근성 충족으로 바꾸어 해석하지 않는다.
- 원본 화면의 알림·인수인계 배너가 지도 영역을 크게 가리는 조합도 있다. “겹침 없음”이라는 과거 요약이 지도 가시성 목표까지 통과했다는 뜻은 아니다.
- 이번 문서 정리에서는 남아 있는 파일과 기록을 대조했으며 위 사용자 시험·접근성 시험을 새로 실행하지 않았다.

검증 시 화면·버전·입력·환경, 수행한 조작, 관찰 결과와 미확인 범위를 함께 남긴다. 전체 방법·번호·옛 승인 절차는 [정리 전 원문](https://github.com/sonic8-8/suri-map/blob/3cd777752e2178ebb3470e6f749b1521ce404e7a/docs/screen-design/measurement-gates.md)에 있다.
