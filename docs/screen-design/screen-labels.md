# 화면 라벨의 의미와 표현

과거 시안의 라벨 선택을 요약한다. 현재 합의한 도메인 의미는 [CONTEXT](../../CONTEXT.md), 실제 화면 문자열은 제품 코드에서 확인한다. 이 표만으로 공개 enum·필드·모든 화면 이름을 일괄 변경하지 않는다.

## 읽기 원칙

- 안내는 짧은 사실과 가능한 다음 행동으로 쓴다. 버튼은 `수색 시작`·`사건 종료`처럼 대상을 드러낸다.
- 설명에는 `-합니다/-됩니다`, 숫자에는 아라비아 숫자를 사용했던 원칙을 유지한다. 영어 코드·내부 ID를 사용자의 업무 용어처럼 노출하지 않는다.
- 수색 차수와 근무 교대, 로컬 저장과 서버 전송 완료를 구분한다.
- `추천`·`위험도`·추측으로 시스템의 판단을 새로 만들지 않는다. 빈 화면에는 사실과 복귀·재시도 방법을 적는다.

## 당시 도메인별 표기

| 의미 | 당시 화면 표기·구분 |
|---|---|
| Incident / MissingPerson | 사건 / 실종자 |
| OperationalPeriod | 수색 차수(OP), OP 1차. 근무 교대·인수인계 차수로 부르지 않음 |
| OP 사유 | 초기 / 재수색 / 수색 범위 변경 / 기타 |
| DutyShift | 근무 구간, 근무 인계. 실제 현장 용어 확인은 남아 있음 |
| PolicePhone | 폴리폰, 팀 폴리폰·순찰차 폴리폰. 업무폰이라는 제품 설명과의 표기는 화면 작업에서 확인 |
| Account | 계정, 지휘 계정·팀 계정. 단말·개인·공유 계정은 같은 개념이 아님 |
| SearchArea | 전체 수색 구역 → 부대 구역 → 팀 구역. 줄여도 계층 의미 유지 |
| SearchPath / Segment | 수색 경로 / 차량 구간·도보 구간·구분 안 됨 |
| 마커 5종 | 단서 / 실종자 발견 / 지형 / 지원 요청 / 운영 메모 |
| 지원 요청 종류 | 드론 / 경찰견 / 기타 지원. 마커의 상위 유형과 구분 |
| HandoverMemo | 인수인계 메모. 마커의 운영 메모와 구분 |
| SearchHistorySummary | 수색 이력 요약. 원본 기록이나 확정 판단을 대신하는 보고서가 아님 |
| OfflinePackage | 오프라인 패키지. 적재 완료와 제한된 지도 진입을 구분 |

짧은 라벨·소속별 표기·마커 코드 대응 전체는 Git 원문에 남겼다. 현장 용어·OP 약어 노출 범위는 운영 사용자 검토가 필요했던 항목이다.

## 상태와 행동

| 상황 | 표현 의도·예시 |
|---|---|
| 불러오는 중 / 데이터 없음 | `불러오는 중` / `배정된 사건이 없습니다`. 아직 못 받은 상태와 구분 |
| 오프라인 기록 | `오프라인 저장됨. 연결 시 자동 전송`. 실제 로컬 저장 성공 뒤 표시 |
| 미전송 / 전송 중 / 동기화 | `미전송 N건` 등. 서버가 수신하지 않았는데 완료로 표시하지 않음 |
| 오래된 위치 | `N분 전 동기화`·마지막 갱신 시각. 위험 판정이나 복구 목표 시간 아님 |
| 접근 거부 / 읽기 전용 | `접근 권한이 없습니다` / 변경 불가 이유를 표시 |
| 실패 | 실패한 대상·입력 보존 여부·`다시 시도` |
| 종료 / 파기 | `종료된 사건` / `데이터 파기 중`. 같은 완료로 표시하지 않음 |
| 수색 조작 | 수색 시작 / 일시정지 / 재개 / 수색 종료 |
| 지휘 조작 | 사건 가져오기 / 구역 분할·할당·완료 처리 / 새 OP / 사건 종료 |
| 기록 조작 | 마커 생성 / 수정·삭제 / 사진 첨부 / 메모 작성 |
| 패키지 부분 실패 | 실패 항목 재시도. 성공 항목까지 전체 재다운로드한다고 안내하지 않음 |
| 강조 알림 | 실종자 발견·지원 요청의 위치·종류·작성 맥락과 확인/지도 이동 |

시각 `HH:mm`, 상대 시간, 좌표 소수 5자리는 당시 표시 가정이다. 시간대·날짜·발생 시각과 수신 시각의 구분은 실제 용도에 맞게 확인한다. 일반 안내의 자동 사라짐과 중요한 발견·지원 요청의 확인 가능성도 구분한다.

전체 라벨표와 검토 항목은 [정리 전 원문](https://github.com/sonic8-8/suri-map/blob/3cd777752e2178ebb3470e6f749b1521ce404e7a/docs/screen-design/screen-labels.md)에 있다.
