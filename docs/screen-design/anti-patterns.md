# 화면에서 혼동시키지 말아야 할 것

과거 화면 검토에서 남길 이유와 사례다. 제품의 자동 판단 금지는 [PRD](../prd.md), 용어는 [CONTEXT](../../CONTEXT.md), 상태·권한의 문서 간 차이는 [화면 상태](screen-state-matrix.md)에서 확인한다.

## 기록을 판단으로 바꾸지 않기

| 피할 표현 | 이유·대신 보여줄 것 |
|---|---|
| 빈 지도에 자동 누락 빗금·“다음 추천 구역”·위험도 | 기록이 없다는 사실이 미수색·위험의 확정은 아님. 원본 경로·사람의 완료 처리·메모를 제공 |
| 자동 “수색 완료도 60%” | 사람이 내릴 완료 판단을 시스템의 계산값으로 오인. 완료자·시각·기록 수처럼 관찰 가능한 사실 표시 |
| 시간 경과만으로 마커·업무폰을 위험 표시 | 통신 최신성과 위험 판단은 다름. 마지막 수신·경과 시각을 표시 |
| AI 요약의 재수색 지시·추측 | 요약은 기록된 사실과 출처를 확인하는 용도. 원본 확인을 막지 않음 |
| 전체 구역을 원천 시스템이 제공했다고 가정 | 가져온 사건 정보와 지휘자가 정한 범위는 별개. 구역 없는 초기 화면 제공 |
| 종료 화면에 사진·좌표·실시간 재구독·패키지 다운로드 | 종료와 파기 요구 위반 가능. 허용된 종료 정보만 표시 |

## 다른 개념을 같은 것으로 표시하지 않기

- 수색 차수(OP)는 근무 교대(DutyShift)가 아니다. 활성 차수와 비교에 선택한 과거 차수도 다르다.
- 업무폰 수는 인원 수가 아니다. 순찰차 업무폰도 소속 조직의 운용 맥락을 유지한다.
- 전체·부대·팀 구역은 계층과 담당을 구분한다. 지도 선이 지나간 것과 사람이 완료 처리한 것은 다르다.
- 마커 5종과 지원 요청의 세부 종류를 혼동하지 않는다. 유형·아이콘·라벨 의미를 맞추고 색만으로 구분하지 않는다.
- 현장 마커 작성, 타인 마커 수정, 사건 가져오기·종료는 같은 권한이 아니다. 앱·웹 경계를 유지한다.
- 과거 차수 선택의 가독성 문제를 이유로 업무상의 누적 차수 상한을 임의로 만들지 않는다.
- 오프라인·전송 대기·서버 수신·처리 불가를 하나의 “성공/실패”로 줄이지 않는다.

## 지도를 읽고 조작할 수 있게 하기

| 피할 패턴 | 이유·대안 |
|---|---|
| 시민 포털의 큰 카드·여백, 지도 중앙의 큰 검색창·리뷰·길찾기·즐겨찾기 | 기록 확인·현장 입력의 핵심 정보가 밀림. 사건·차수 맥락과 지도 우선 |
| 같은 위치의 마커를 덮어 마지막 하나만 표시 | 묶음 수·펼침 등으로 존재를 알리고 강조 알림이 가려지는지 확인 |
| 경로와 구역을 같은 시각으로 표시 | 선·면, 점선·투명도·라벨로 구분. 지도 텍스트는 배경/외곽선으로 읽기 확보 |
| 단순 보기 토글만 있고 숨기는 내용이 불명확 | 숨긴 레이어·필터를 알 수 있게 표시 |
| 위치 갱신 시각을 hover에서만 제공 | 평소에도 경과 시간·외곽선 등으로 식별 |
| 핵심 행동을 한 손으로 닿기 어려운 곳에 배치 | 큰 터치 영역·간격·하단 배치 검토. 실기기에서 확인 |
| 짧은 길게 누르기만으로 삭제·종료 확정 | 장갑·습기·우발 접촉 위험. 명시적 확인, 실제 가능한 경우에만 실행 취소 |
| 중요한 알림이 금방 사라지거나 모달에 가림 | 발견·지원 요청을 확인할 수 있도록 유지·이동 동선 제공 |
| 끝없는 스피너·빈 권한 화면 | 진행 상태·실패 영역·재시도·문의 이유 표시 |
| 사건 전환 때 맥락 소실, 비교하려고 현재 지도 이탈 | 같은 사건·차수·선택 상태를 유지할 방법 검토 |

구체 크기·경고 횟수·시간은 [토큰 기록](dense-tokens.md)과 [검증 항목](measurement-gates.md)의 가정이다. 문서의 숫자만으로 접근성이나 현장 사용성 통과를 선언하지 않는다.

전체 사례·옛 절 번호는 [정리 전 원문](https://github.com/sonic8-8/suri-map/blob/3cd777752e2178ebb3470e6f749b1521ce404e7a/docs/screen-design/anti-patterns.md)에 있다. 비어 있던 사례 로그와 일괄 reject 절차는 제거했다.
