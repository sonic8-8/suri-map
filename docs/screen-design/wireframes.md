# Wireframes — 비-Hero 13개 화면

상태: 2차 (2026-05-05). 각 화면 = IA 명세 + ASCII 박스 wireframe.

## 목적

Hero 3개는 HTML mock(`artifacts/lo/`)으로 정교화. 나머지 13개는 이 문서에 **IA 명세 + ASCII 박스 다이어그램**으로 표현. 본 개발 시 화면 IA·layout 즉시 참조 가능.

베스트 프랙티스:
- **Hero 3-5개**: 정체성·핵심 패턴 검증을 위한 정교한 HTML mock
- **나머지**: ASCII wireframe + 텍스트 명세
- **재사용**: nonHero 화면은 Hero 패턴 재사용으로 빠르게 구현

## Hero 3개 (별도 HTML mock)

| 검증 영역 | 화면 | 산출물 |
|---|---|---|
| 정보 dense dashboard | Web 사건 상황판 메인 | `lo-web-situation-board-main-v1.3.html` |
| Rugged field UI | Polifon 수색 중 지도 | `lo-polifon-search-map-v1.html` |
| 빠른 입력 (바텀시트) | Polifon 마커 생성 바텀시트 | `lo-polifon-marker-bottomsheet-v1.html` |

위 3개로 다음이 다 검증됨:
- 마커 7종 SVG 글리프 + 라벨 칩 시스템
- 구역 3계층 (OVERALL/UNIT/TEAM)
- OP/DutyShift 시각 분리
- 폴리폰 freshness (60초/5분 spec)
- 권한 차등 (command vs partial)
- 상태 분기 (default/loading/empty/error/permission/offline/partial_sync/stale/incident_closed)
- 다크 모드 + 야외 가시성
- thumb zone

## Wireframe 명세 (이 문서)

각 화면당 다음 항목:

- **연결 SC**: harness-scenarios.md
- **주 사용자**: PRD §8.4 권한 매트릭스
- **IA**: 화면 영역 구성 (한 줄)
- **핵심 행동 1-3개**: 사용자가 이 화면에서 하는 일
- **상태 분기**: screen-state-matrix.md 참조 (필수 분기만)
- **재사용 컴포넌트**: Hero 3개에서 정의된 패턴
- **신규 컴포넌트**: Hero에 없는 것만
- **권한 분기**: 액션별 가시성·활성화

## 진행 정책

- 각 화면 1회만 작성. iteration 안 함.
- 정합성 위반 발견 시 wireframe 본문 수정 + 메모만 추가
- 본 개발 단계에서 화면이 더 정교화 필요해지면 그때 HTML mock 또는 high-fi
- High-fi/인터랙티브 프로토타입은 디자이너 또는 후속 단계 작업

## W8. 사건 종료 / 파기 상태

- **연결 SC**: SC-12
- **주 사용자**: 종료 = 실종팀 간부만. 파기 상태 조회 = 모든 배정 계정
- **IA**: 사건 요약 카드 + 종료 전 = [사건 종료] 강조 빨강 CTA + confirm 모달 (실종자명 입력 등) + 종료 후 = sanitized tombstone (사건 ID + 종료 시각 + 종료자 + 파기 진행 항목별 상태)
- **핵심 행동**: ① 사건 종료 (실종팀 간부, confirm 다이얼로그) ② 파기 진행 상태 조회
- **상태**:
  - default (종료 전): 사건 요약 + [종료] CTA (강조 빨강 + confirm)
  - default (종료 후): tombstone (anti-patterns §1.6.7.1 — 실종자/위치/사진 모두 제거)
  - loading (종료 처리 중)
  - error (종료 실패 → 사유 + 재시도)
  - permission_denied (실종팀 간부 외는 [종료] 숨김. 파기 상태만 조회 가능)
  - offline ([종료] 비활성 + 안내)
  - incident_closed (이미 종료 — tombstone 표시. 재오픈 UI 없음 ADR-0022)
  - purging (항목별 진행률: 실종자 정보 ✓ / 위치 좌표 ✓ / 단말 로컬 진행 중)
- **재사용**:
  - Hero 1 헤더
  - 상태 배지 (Hero 1)
- **신규**:
  - 종료 confirm 모달 (실종자명 입력 등 destructive guard)
  - tombstone view (sanitized — anti-patterns §1.6.7.1)
  - 파기 진행 status (incident_data_purge 행 기반)
- **권한**: [종료] = 실종팀 간부 only. 파기 상태 조회는 모든 배정 계정
- **참고**: tombstone에서 보여줄 것 = 사건 ID, 종료 시각, 종료자, 비식별 사건 메타, 파기 진행 항목별 상태. 보여주면 안 되는 것 = 실종자명·사진·인상착의·폴리폰 위치·실시간 stream·패키지 재다운로드 링크
